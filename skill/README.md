# Skills

- [`irecord-headless/SKILL.md`](irecord-headless/SKILL.md) — record the macOS screen, a window, or a region from an LLM agent with the `irecord` CLI. Covers permissions, target discovery, synchronous and background recordings, pause/resume/stop, JSON parsing, and error recovery.

The skill follows the common `SKILL.md` convention (YAML frontmatter with `name` and `description`). Load it into an agent that can execute shell commands on macOS 15+.

- `irecord help --json` — machine-readable capability contract
- `README.md` / `README_en.md` — installation and full CLI reference
